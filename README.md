## Descripción

Sistema de gestión desarrollado para registrar y consultar información
relacionada con clientes, productos y pedidos.

El proyecto tiene como finalidad aplicar un sistema de control
de versiones utilizando Git y GitHub.

## Funcionalidades principales

### Módulo de clientes
- Registrar cliente.
- Listar clientes.

### Módulo de productos
- Registrar producto.
- Listar productos.

### Módulo de pedidos
- Registrar pedido.
- Consultar pedidos.
